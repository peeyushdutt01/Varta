# [Varta Chat](https://vartachat.netlify.app/)

Varta Chat is a modern, real-time messaging application designed to provide a seamless and secure communication experience. Built with a focus on performance and user experience, it allows users to connect instantly with friends and colleagues through an intuitive interface.

## 🚀 About the Project

"Varta" (वार्ता) translates to "conversation" or "talk" in Sanskrit/Hindi. This project aims to bridge the gap between users with instant, reliable messaging. whether you are catching up with a friend or collaborating with a team member, Varta Chat ensures your messages are delivered instantly.

The application features a clean, responsive design that works effectively across devices, ensuring you stay connected wherever you are.

## ✨ Key Features

- **Real-Time Messaging**: Experience instant communication with low-latency message delivery powered by WebSocket technology.
- **Secure Authentication**: Robust user account management including secure Sign Up, Login, and Logout functionality using JWT (JSON Web Tokens).
- **User Profiles**: Personalize your identity with profile pictures and user details.
- **Responsive UI**: A sleek, mobile-first interface built with Tailwind CSS that adapts to any screen size.
- **Live Connectivity Status**: See when you are connected and when messages are being sent or received in real-time.
- **Multiple Themes**: Choose a theme which suits you best.
- **Toast Notifications**: Get instant feedback on your actions (login success, errors, etc.) for a smooth user experience.

## 🛠️ Technologies Used

**Frontend:**
- React.js
- Tailwind CSS (Styling)
- Zustand (State Management)
- Axios (API Integration)

**Backend:**
- Node.js
- Express.js
- MongoDB (Database)
- Socket.io (Real-time communication)
- JWT (Authentication)
